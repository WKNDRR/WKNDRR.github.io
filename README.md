# weekender.github.io
## Studio

`studio/` est un outil de post-production photo qui tourne entièrement dans le navigateur (aucune image n'est envoyée sur un serveur) : https://wkndrr.github.io/studio/

- Pellicule : film 35 mm (Portra, Ultramax, Kodachrome…), Instax avec cadre, diptyque / triptyque.
- Effets empilables : vitesse d'obturation, stroboscope, teinte sélective, sérigraphie, balayage, exposition multiple, zoom, prisme, filtre étoile, halo, flou, aberration chromatique, moyen format, réglages, bichromie, gélatines, double exposition, grain.
- Chaque effet a une opacité et une zone d'application.
- Export JPEG / PNG / WebP en pleine résolution.
- `engine.js` : moteur WebGL2 et shaders. `app.js` : interface.
